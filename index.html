Quick start

            
    
              
  1. Write RISC-V (RV32IM) assembly in the editor, or pick one of the Examples.
    2. 
              
  2. Add parts with the toolbar above the board. Wire a part by clicking one of its pins and then a GPIO pin on the board (or choose the GPIO in the part's settings panel). Ground / 3V3 are connected automatically while Auto power is ON. The Wires menu switches between curved wires and horizontal / vertical wires; with the latter, click while wiring to place points. If a point is diagonal to the previous one, the wire bends at a right angle, first along the direction you moved the mouse (move back near the previous point to choose again). Backspace removes the last point. To edit a wire afterwards, click it: drag a round handle to move a corner, drag a bar handle to move a segment (this adds corners where the segment meets a pin), and double-click a corner to remove it. Turn Auto power OFF to wire each part's supply pin to a GND or 3V3 pin yourself: a part without power doesn't work, and the rail you choose sets its wiring mode (for example, an LED's fixed leg on 3V3 makes it active-low).
    3. 
              
  3. Press ▶ Run (F5). Use Step (F10), breakpoints (click a line number) and ebreak to debug. Choose a slow speed such as 10 Hz (trace) to watch each instruction execute.
    4. 
            


            
Memory map

            

              
AddressRegion

              
0x40380000.text — your code (internal SRAM, instruction bus)

              
0x3FCA0000.data / .bss / .rodata — your variables

              
0x3FCDFFF0initial stack pointer sp (stack grows down); gp = start of .data

              
0x60000000UART0

              
0x60004000GPIO

              
0x60009000IO_MUX (MCU_SEL, FUN_IE, FUN_WPU, FUN_WPD are modelled)

              
0x60023000SYSTIMER (16 MHz counter)

              
0x60043000USB Serial/JTAG (EP1 writes go to the serial monitor)

            

            
Execution starts at _start, else main, else the first instruction. Other peripheral addresses (0x60000000–0x600D0FFF) read back what was written, so watchdog and clock setup code does no harm.

IO_MUX (base 0x60009000)

            
IO_MUX_GPIOn_REG = 0x60009004 + 4·n. As on the real chip:

            

              
BitNameEffect

              
14:12MCU_SELIO MUX function (0, 1 or 2). Function 1 is always GPIOn; only pins in a GPIO function are driven by GPIO_OUT / GPIO_ENABLE.

              
9FUN_IEInput enable. When 0, the pin always reads 0 in GPIO_IN_REG.

              
8FUN_WPUInternal pull-up

              
7FUN_WPDInternal pull-down

            

            
A button only connects its pin to GND (or 3V3) while pressed. When released the pin is floating unless a pull resistor is enabled, so set FUN_IE | FUN_WPU for a button to GND (or FUN_IE | FUN_WPD for a button to 3V3). Reading a floating pin or a pin with FUN_IE = 0 prints a warning in the serial monitor. Reset values follow the "After Reset" column of the datasheet's pin table: GPIO2–5, 7, 8 and 10 have IE = 1 and no pull; GPIO6 (MTCK), GPIO9 and GPIO12–17, 20 have IE = 1 and a pull-up; GPIO21 (U0TXD) has a pull-up only; GPIO0/1, 11, 18, 19 have IE = 0. GPIO19 (USB D+) is also pulled up by the USB PHY.

            
After reset MCU_SEL = 0 on every pin, and function 0 is not GPIO on all of them:

            

              
PinsFunction 0To use as GPIO output

              
GPIO0–3, 8–11, 18, 19GPIOnworks directly

              
GPIO4–7JTAG (MTMS, MTDI, MTCK, MTDO)set MCU_SEL = 1

              
GPIO12–17SPI flash (SPIHD … SPIQ)

              
GPIO20, 21U0RXD, U0TXD (GPIO21 is driven high by the idle UART)

            

            
Writing GPIO_OUT for an output pin that is not in a GPIO function prints a warning. Inputs (GPIO_IN_REG) work in any function as long as FUN_IE = 1. Other fields (FUN_DRV, …) read back what was written.

Simulator ecall services

            
Simulator-only conveniences (like RARS/Venus) — real hardware has no OS to answer them. Put the service number in a7, the argument in a0.

Assembler

            
Instructions: all of RV32I and the M extension, plus Zicsr (csrrw/s/c[i]), ecall, ebreak, fence, wfi, mret.

            Pseudo-instructions: nop li la mv not neg seqz snez sltz sgtz beqz bnez blez bgez bltz bgtz bgt ble bgtu bleu j jr jal label ret call tail csrr csrw csrs csrc rdcycle rdtime rdinstret, lw rd, label and sw rs, label, rt.

            Directives: .text .data .bss .rodata .section .equ/.set (or NAME = value) .word .half .byte .ascii .asciz/.string .space/.zero .align .balign .globl.

            Expressions: + - * / % << >> & | ^ ~, parentheses, 'c' characters, 0x/0b numbers, %hi(sym)/%lo(sym).

            Labels: name: and numeric local labels (1: referenced as 1b / 1f). Comments start with #, // or ;, or use /* … */.


            
Board pins (ESP32-C3-DevKitM-1)

            
Usable GPIOs: 0–10 and 18–21. GPIO9 is the on-board BOOT button (active low). GPIO20/21 are UART0 RX/TX, GPIO18/19 USB. The RST button restarts the program.


            
Keyboard

            
F5 run/pause · F10 step · Ctrl+Enter restart · Ctrl+S save in browser · Del delete selected part/wire · Esc cancel wiring. Buttons can be given a keyboard key in their settings.
